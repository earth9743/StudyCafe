# 카공지도 (Kagong Map) — 제품 요구사항 문서 (PRD)

> **버전:** 1.0.0
> **최종 업데이트:** 2026-03-13
> **상태:** 초안 (Draft)

---

## 1. 요약 (Executive Summary)

카공지도(Kagong Map)는 카페에서 공부하는 '카공족' 문화를 위한 실시간 정보 공유 플랫폼이다. 학생과 재택근무자가 주변 카페의 현재 혼잡도, 콘센트 가용성, 소음 수준을 실시간으로 확인하고 직접 보고할 수 있도록 하여, 최적의 카공 장소를 빠르게 찾을 수 있게 돕는다. Flutter 기반으로 Android, iOS, Web을 동시 지원하며, 네이버 지도 위에 사용자 생성 실시간 데이터를 시각화하는 방식으로 차별화한다.

---

## 2. 문제 정의 (Problem Statement)

카공족(카페에서 공부하는 사람들)이 겪는 반복적인 문제:

1. **혼잡 여부 미인지:** 카페에 도착해서야 자리가 없다는 것을 알게 됨
2. **콘센트 부족 불확실성:** 노트북 사용 시 콘센트 위치와 가용 여부를 미리 알 수 없음
3. **소음 환경 미파악:** 공부에 적합한 조용한 카페인지 방문 전에는 알 수 없음
4. **정보의 단절:** 카카오맵/네이버맵의 기본 정보(위치, 영업시간)만으로는 카공 적합성 판단 불가

**기회:** 사용자 집단이 실시간으로 서로의 경험 데이터를 공유하는 구조를 만들면, 방문 전 의사결정에 필요한 정보를 모두 해결할 수 있다.

## 3. 목표 및 비목표 (Goals & Non-Goals)

### 목표 (Goals)
- 현재 위치 기반으로 반경 내 카페 목록 및 지도 표시
- 사용자가 직접 혼잡도 / 콘센트 가용성 / 소음 수준을 보고
- 집계된 실시간 데이터를 지도 마커 및 상세 화면에서 시각화
- 텍스트 + 사진 리뷰로 카페 품질 정보 축적
- Android / iOS MVP 출시

### 비목표 (Non-Goals)
- 카페 예약 및 주문 기능 (배민, 카카오 등 외부 서비스 영역)
- 카페 업주 전용 관리 대시보드 (v2 이후 고려)
- AI 기반 자동 혼잡도 예측 (데이터 축적 후 v2 이후 고려)
- 유료 구독 또는 광고 수익화 모델 (v2 이후 고려)
- 실시간 채팅 기능

## 4. 사용자 페르소나 (User Personas)

### Persona A — 대학생 카공족 "민지" (22세)
- 도서관 대신 카페에서 공부하는 대학생
- 하루 평균 2~3곳의 카페 방문
- 스마트폰 중심 사용자, 앱 전환이 많음
- 핵심 니즈: 지금 당장 자리가 있는지, 콘센트가 있는지 알고 싶음

### Persona B — 재택근무자 "준호" (30세)
- 집에서 집중이 어려워 카페 작업 선호
- 맥북 사용으로 콘센트 필수
- 소음 환경 민감, 미팅 없는 날은 조용한 카페 선호
- 핵심 니즈: 소음 수준 + 콘센트 조합 필터링

### Persona C — 스터디 그룹 리더 "소연" (26세)
- 3~4명 그룹을 위한 넓은 자리 카페 탐색
- 미리 카페 탐색 후 단체 방문
- 핵심 니즈: 최근 리뷰와 현재 혼잡도로 방문 전 판단

## 5. 사용자 스토리 (User Stories)

### Epic 1: 인증 (Auth)
```
[P0] US-001: 새 사용자로서, 이메일과 비밀번호로 회원가입하여 서비스를 이용할 수 있다.
  - AC1: 이메일 형식 유효성 검사
  - AC2: 비밀번호 최소 8자, 영문+숫자 포함 강제
  - AC3: 중복 이메일 가입 시 명확한 에러 메시지 표시
  - AC4: 회원가입 성공 시 홈 화면으로 이동

[P0] US-002: 기존 사용자로서, 이메일/비밀번호로 로그인할 수 있다.
  - AC1: 잘못된 자격증명 시 명확한 에러 메시지
  - AC2: 로그인 성공 시 마지막 화면으로 복귀

[P1] US-003: 사용자로서, Google 계정으로 소셜 로그인할 수 있다.
  - AC1: 구글 로그인 성공 시 프로필 사진, 이름 자동 설정
```

### Epic 2: 카페 탐색 (Discovery)
```
[P0] US-004: 사용자로서, 현재 위치 근처 카페를 지도 위에서 볼 수 있다.
  - AC1: 위치 권한 허용 후 현재 위치 중심으로 지도 표시
  - AC2: 카페 위치에 마커 표시
  - AC3: 마커 색상이 현재 혼잡도를 반영 (여유=초록, 보통=주황, 혼잡=빨강)

[P0] US-005: 사용자로서, 마커를 탭하여 카페 요약 정보를 볼 수 있다.
  - AC1: 카페 이름, 현재 혼잡도, 콘센트 가용성, 평점 표시
  - AC2: 상세 보기 버튼 탭 시 상세 화면으로 이동

[P0] US-006: 사용자로서, 카페 상세 정보 화면에서 전체 정보를 확인할 수 있다.
  - AC1: 카페 이름, 주소, 영업시간, 전화번호 표시
  - AC2: 현재 혼잡도, 콘센트 상태, 소음 수준 표시
  - AC3: 보고 기준 시간 표시 ("N분 전 N명 보고")
  - AC4: 평균 별점 및 리뷰 수 표시
```

### Epic 3: 실시간 보고 (Reporting)
```
[P0] US-007: 사용자로서, 카페의 현재 혼잡도를 보고할 수 있다.
  - AC1: 여유 / 보통 / 혼잡 중 하나 선택
  - AC2: 보고 즉시 해당 카페 혼잡도 업데이트
  - AC3: 30분 이내 동일 카페 재보고 불가 (UI에서 비활성화)
  - AC4: 보고 성공 시 토스트 메시지 표시

[P0] US-008: 사용자로서, 카페의 콘센트 가용 상태를 보고할 수 있다.
  - AC1: 충분히 있음 / 일부 있음 / 없음 중 선택
  - AC2: 보고 즉시 상태 업데이트

[P0] US-009: 사용자로서, 카페의 소음 수준을 보고할 수 있다.
  - AC1: 조용함 / 보통 / 시끄러움 중 선택
  - AC2: 보고 즉시 상태 업데이트
```

### Epic 4: 리뷰 (Reviews)
```
[P0] US-010: 사용자로서, 방문한 카페에 리뷰를 남길 수 있다.
  - AC1: 별점 (1~5점) 필수 입력
  - AC2: 텍스트 리뷰 최대 500자
  - AC3: 카테고리 태그 선택 (복수 선택 가능)
  - AC4: 제출 후 리뷰 목록에 즉시 반영

[P1] US-011: 사용자로서, 리뷰에 사진을 첨부할 수 있다.
  - AC1: 최대 3장 선택 가능
  - AC2: 업로드 진행 상태 표시
  - AC3: 업로드 실패 시 재시도 옵션 제공

[P0] US-012: 사용자로서, 카페의 다른 사용자 리뷰 목록을 볼 수 있다.
  - AC1: 최신순 기본 정렬
  - AC2: 작성자 닉네임, 별점, 날짜, 내용 표시
```

### Epic 5: 마이 페이지 (Profile)
```
[P0] US-013: 사용자로서, 내 프로필 정보를 볼 수 있다.
  - AC1: 닉네임, 프로필 사진, 총 보고 횟수, 총 리뷰 수 표시

[P1] US-014: 사용자로서, 내 닉네임과 프로필 사진을 변경할 수 있다.
  - AC1: 닉네임 2~20자 제한
  - AC2: 사진 업로드 후 Firebase Storage 저장 및 프로필 즉시 반영

[P1] US-015: 사용자로서, 내가 작성한 리뷰 목록을 볼 수 있다.
  - AC1: 최신순 정렬
  - AC2: 각 리뷰 탭 시 해당 카페 상세 화면으로 이동
```

## 8. 수용 기준 (Acceptance Criteria) — 주요 기능

### MVP 출시 기준 (Phase 1~3 완료)
- [ ] 신규 사용자가 회원가입부터 카페 발견까지 60초 이내 완료 가능
- [ ] 지도에서 현재 위치 기반 카페 마커 표시 정상 동작
- [ ] 혼잡도 보고 후 1초 이내 화면 반영
- [ ] Android / iOS 양쪽에서 충돌 없이 핵심 흐름 동작
- [ ] 소스 코드 어디에도 Naver Client ID 하드코딩 없음
